# DreamPost

DreamPost
This app is merant to build a community for sharing ideas posts from the admin to the members. Here the members can interact (like, share with admin only, comment visible to admin & member himself). Members can chat with admin , send messages & images in chats. In chat members can download the media shared by admin only with no delete option. Members can edit profile photo, app themes(10 classy pastel thems with oled black theme as an option).
Members can use a valid gmail for signup & login.
Admin has to login with credentials. He can approve the members for using the app. Unless the member is approved they can check profile setting & chat section. Community post & send message option will be locked until the profile is approved. Once the member is verified all profile input details will be locked. 
Admin can post images & videos on community post along with the caption & people have the option to comment on that post with text emoji & images ( visible to admin & members only). Admin will get crop the image option before posting on community post & admin can share upto 5-7 images at once.
Admin can manually set limit on size of images & video shared within the app in admin profile section.
Admin can block any member at any time.
Admin panel will have the community post tab, chat tab, members profile section, admin profile section where admin can change admin userid & password at any time along with the app themes.

Note: members can view community post only after when their profile is verified by admin. Members can receive message from admin but cant send messages until their profile is validated or any restriction is imposed.
Admin can impose restriction like community post restriction, send message restriction, account suspended. These option will be available to admin in members profile section.
Members can chat with members only & can see only the post made by admin& their own comment made on the post.
Admin can delete any unwanted comment & message anytime (with out any traces).
No any media of community post can be shared outside outside the app with restricted screenshot.
